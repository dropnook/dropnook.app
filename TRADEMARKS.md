# The Dropnook™ name

The code of Dropnook is free software under the
[GNU Affero General Public License v3.0](LICENSE). That license covers the
code — not the name **Dropnook™** or its logo, which identify this project
and its official releases. (AGPL-3.0, section 7(e), allows exactly this.)

**You may**

* use, change and share the code as the license allows;
* say that your work is *based on Dropnook*, *works with Dropnook* or is a
  *fork of Dropnook*;
* pass on the official, unchanged images and releases under their name;
* write about Dropnook, review it, show it in videos and tutorials.

**Please don't**

* call a changed version, a fork or a service built on it "Dropnook" or a
  name easily mistaken for it, or use the logo for it;
* suggest that the project endorses you or your product when it does not.

Forks are welcome — pick a name of your own and mention that it is based on
Dropnook, with a link to <https://github.com/dropnook/dropnook.app>.

If you are unsure, open an issue and ask.
